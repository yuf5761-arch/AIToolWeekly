### 1. Strawberry 1.0
- **我们的总结：**瑞典团队做的 AI 浏览器，结束测试，推出 1.0 正式版。浏览器里的 AI 助手可以替你查资料、整理会议记录、写跟进邮件，还能按时间表或事件自动执行任务。【事实】
- **要点：**本条未实测，以下信息来自出处页面。1.0 版的更新主要是助手外观可以自己设计，另外加了一个让助手“待命”的公共空间；10-21 的更新加入了日常聊天模式、WhatsApp 连接和能区分说话人的会议记录。【事实】
- **价格和门槛：**据 Strawberry 官方定价页（2026-10-27 查阅），免费版每月 500 积分；付费版每月 $20、$85、$250 三档，积分不同。官方称普通浏览不消耗积分，只有助手出手做事时才扣。【事实】支持的系统为 macOS 和 Windows【二手：来自 TheNextWeb 等报道】。国内访问：未确认。
- **出处链接：**
  - 原文：<https://strawberrybrowser.com/blog> （更新日志，2026-10-26）
  - 官方：<https://strawberrybrowser.com/pricing>

### 2. Kimi K3.1 Pro
- **我们的总结：**月之暗面（Moonshot AI）的新模型，官方称是 K3.1 系列的首个模型，100 万上下文，重点提升了编程、3D 创作、金融研究和 Agent 任务。同时推出了速度更快的 Highspeed 版。【事实】
- **要点：**本条未实测，以下信息来自出处页面。据 Kimi 官方博客（2026-10-23），Highspeed 版速度是标准版的 2–3 倍；完整模型权重将在 11-04 前放出。可以在 Kimi 网页版、Kimi Work、Kimi Code 和 Kimi API 里使用。【事实】
- **价格和门槛：**据 Kimi 官方定价页（2026-10-27 查阅），国际站 API 标准版每百万 tokens 输入 $2、输出 $10，Highspeed 版翻倍。官方称会员方案免费档可有限使用，Highspeed 需要 Pro 及以上会员。【事实】API 需先充值才能解锁，官方称最低充值 $1。【事实】国内站价格：未确认。
- **出处链接：**
  - 原文：<https://www.kimi.ai/blog/kimi-k3-1-pro> （10-23）
  - 官方：<https://www.kimi.ai/resources/kimi-k3-1-pro-pricing>

- **要点：**本条未实测，以下信息来自出处页面。个人 Google 账号和 Workspace 用户都能用；欧洲经济区默认关闭，其他地区默认开启，可在 Gemini App 的“连接应用”设置里开关。【事实】
- **价格和门槛：**是否需要付费套餐：官方页面未写明，未确认。国内：Google 服务在中国大陆无法直接访问【二手】。

- **要点：**本条未实测，以下信息来自出处页面。官方称 Turbo 在 Artificial Analysis 语音合成榜上排名居首。免费期内官方不承诺可用性和延迟，免费额度满了会返回 429 错误；专业克隆音色仍需用标准版模型。【事实】

- **价格和门槛：**据 Cohere 官方博客（2026-10-21），API 每百万 tokens：Pro $0.05，Fast $0.02。【事实】国内访问：未确认。
- **出处链接：**

### 8. Qwen3.8-27B BaseQuant
- **我们的总结：**第三方团队 BaseCompute 发布的 Qwen3.8-27B 量化版，分小、中、大三个尺寸，体积与 Unsloth 同档版本相同，目标是让本地跑的 Agent 更接近原版模型的表现。【事实】
- **要点：**本条未实测，以下信息来自出处页面。官方称在 3 位和 4 位量化下，与原模型的偏差（KL 散度）比 Unsloth 同尺寸版本低 15%。据 BaseCompute 官方博客（2026-10-22），中号文件约 16.4GB，可用 llama.cpp 运行。【事实】
- **价格和门槛：**免费下载。量化版的许可是否沿用 Qwen3.8 原许可：未确认。国内访问 Hugging Face：未确认。

### 9. Simular Agent S4
- **我们的总结：**Simular 开源的“电脑操作 Agent 研究员”。它自己不做任务，而是观察操作电脑的 Agent 怎么干活，再自动改写这些 Agent 能用的工具接口，比如把逐格填表换成一次批量写入。【事实】
- **要点：**本条未实测，以下信息来自出处页面。据 Simular 官方文章（2026-10-21），搭配 Qwen3.8-27B 和进化出的接口库，在 OSWorld V2 上达到 21.3%，是固定接口时的 3.8 倍，成本约为 GPT-5.5 的 4.3%。官方说明这个基准按严格的成败计分。【事实】
- **价格和门槛：**代码开源，Apache-2.0 许可，Python 3.12 以上。【事实】官方的复现流程要在 AWS 虚拟机上跑评测任务，门槛偏高，更适合研究者和做 Agent 的开发者。国内访问 GitHub：未确认。
- **出处链接：**
  - 原文：<https://www.simular.ai/articles/agent-s4-evolving-the-interfaces-computer-use-agents-work-throughagen> （10-21）
  - 官方：<https://github.com/simular-ai/agent-s>

### 10. Maverick 1.1
- **我们的总结：**土耳其 Manisa Celal Bayar 大学 XR 实验室做的 4B 小模型，在 Qwen3-4B 上微调，把口头或打字的指令变成 Unity 场景里的操作，比如抓取、放置、开关灯。1.1 版加入了撤销、指向和跨房间操作。【事实】
- **要点：**本条未实测，以下信息来自出处页面。新增第 12 个工具“撤销”，可以撤回最近 1–3 条指令；据作者博客（2026-10-23），跨房间操作的成功率从 1.0 版的 33.3% 提到 97.8%。4 位量化文件约 2.5GB，官方称能在 4GB 显存的笔记本上离线运行，不需要 API 密钥。【事实】
- **价格和门槛：**免费，Apache-2.0 许可。【事实】需要会用 Unity，适合做 XR 或游戏交互的开发者。下载需要访问 Hugging Face，国内访问：未确认。
- **出处链接：**
  - 原文：<https://huggingface.co/blog/ErenAta00/maverick-1-1-undo-pointing-other-rooms> （10-23）
  - 官方：<https://huggingface.co/ErenAta00/Maverick-4B-Unity-XR-Agent-1.1>
