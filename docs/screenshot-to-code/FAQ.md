# 常见问题（FAQ）

**这是官方版本吗？**
不是。这是社区汉化版，非官方。原项目 https://github.com/abi/screenshot-to-code ，作者 Abi Raja，MIT 许可。原作者与本汉化无关。

**买的是什么？**
源码本身是 MIT 开源、免费的。本包提供的是中文界面、一键启动脚本、中文教程和配置说明。

**生成效果有保证吗？**
没有。效果完全取决于你用的模型。**免费模型不稳定**：会限流、出错、变慢或突然下线，我们不承诺效果、速度和可用性。

**一定要花钱吗？**
本包不含任何模型额度。默认的 Kimi 和备选的硅基流动都是按量计费（新账号可能有赠送额度，以官方为准）；想完全不花钱可以用 OpenRouter 的 `:free` 免费模型（不稳定，有每日/每分钟请求上限）。各服务按它们的规则计费，余额用完会报「余额不足」。

**Key 会被保存或上传吗？**
页面里填的 Key 只在当前页面内存里，刷新即丢，不写入浏览器存储和硬盘（我们实测检查过 localStorage）。Key 只会发给你自己填的接口地址。本包不含任何 Key。请不要把 Key 发给别人，也不要写进 .env 后分享整个目录。

**服务商出错（429/502）会自动重试吗？**
默认**不会**（`OPENAI_MAX_RETRIES=0`），避免悄悄多花免费额度。你可以：① 等一会儿点消息下方的「重试」；② 在 `screenshot-to-code/backend/.env` 把 `OPENAI_MAX_RETRIES` 改成 1，重启后出错会自动再试一次（每次重试都算一次请求）。

**为什么生成的页面里没有直接贴上我的截图？**
社区版默认把截图只当参考图（`SCREENSHOT_REFERENCE_ONLY=1`），让模型用代码画出来，而不是把整张截图贴进页面。想恢复原版行为可改成 0。

**可以拿别人的网站截图来生成吗？**
**不可以。** 禁止用本工具抄袭、复制他人的网站或设计。只能用于你自己的设计稿，或你已经获得授权的素材。由此产生的侵权责任由使用者自行承担。

**国内模型能用吗？推荐哪个？**
**默认 Kimi `kimi-k2.6`，备选硅基流动 `Qwen/Qwen3-VL-32B-Instruct`，DeepSeek 暂不支持。** 2026-10-27 实测：Kimi 在 1 张简单图和 2 张复杂页（后台仪表盘：侧栏+数据卡片+表格；价格页：三栏方案卡片+对比表）上都写出了版式接近的页面，每张约 40–85 秒；硅基流动在简单图上能出页面，但要 2–5 分钟、排版偏差更大；DeepSeek 测试账号余额为 0，未能实测。测试图都是我们自己做的页面，你的设计稿效果不保证。

**报「余额不足 / Insufficient Balance / 402」怎么办？**
说明该服务商账号没钱了或赠送额度用完。去对应平台充值或换一家；本工具不会替你付费。

**Windows / Mac 能用吗？**
脚本已写好，但**未实测**。Linux 已实测。遇到问题请看《教程/04_常见报错.md》。

**能用“输入网址自动截图”吗？**
那需要第三方 ScreenshotOne 的 Key（付费服务），本教程不涉及；而且同样只限你自己的网站或已获授权的页面。

**`screenshot-to-code/tools/mock_responses_server.py` 是什么？**
开发者自测用的本地模拟接口，返回固定的“本地模拟接口输出，非模型生成”页面，用来检查程序链路是否通。它不是模型，普通使用不需要它。
