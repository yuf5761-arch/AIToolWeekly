# 01 安装与启动

1. 安装 Node.js 20+：到 https://nodejs.org 下载 LTS 版安装（国内镜像 https://npmmirror.com/mirrors/node/ ）。装完在终端输入 `node -v`，显示 v20 或更高即可。
2. 解压本包到一个**路径里没有空格的英文目录**更稳妥（例如 `D:\s2c` 或 `~/s2c`）。中文路径在 Linux 实测可用，Windows/mac 未测。
3. 运行启动脚本（见《一键启动说明.md》）。第一次会下载依赖，几分钟到十几分钟不等；以后再启动很快。
4. 终端出现 `[5/5] 启动后端…` 后，浏览器打开 http://127.0.0.1:5173 。
5. 首页顶部能看到“社区汉化版（非官方）”的提示条，说明启动成功。

> Linux 已实测；macOS、Windows 脚本**未实测**，遇到问题请按《04_常见报错》排查。
