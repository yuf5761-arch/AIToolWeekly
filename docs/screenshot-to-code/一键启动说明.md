# 一键启动说明

| 系统 | 脚本 | 状态 |
|---|---|---|
| Linux | `start_linux.sh` | 2026-10-27 在 Linux 上从解压后的包实测：后端、前端均启动，页面可打开（用本地模拟接口跑通链路，不代表模型效果）。注意：测试机已有 uv/pnpm 缓存，不是完全“冷”安装。 |
| macOS | `start_mac.command` | **未实测** |
| Windows | `start_windows.bat` | **未实测** |

## 前置条件
- **Node.js 20 或更新**（必须自己装：https://nodejs.org ，国内可用 https://npmmirror.com/mirrors/node/ ）。脚本会检查版本，太旧会直接提示退出。
- 能联网（首次要下载 uv、Python 3.12、后端和前端依赖，约几百 MB）。
- Python 不用自己装：脚本会用 uv 装一个独立的 Python 3.12 到 `screenshot-to-code/backend/.venv`。

## 脚本做了什么（5 步）
1. 检查 Node.js 版本；
2. 没有 uv 就安装 uv；用 uv 建 Python 3.12 虚拟环境；
3. 安装后端依赖（`backend/requirements.txt`）；
4. 第一次运行时把 `backend/.env.example` 复制成 `backend/.env`（**不含 Key**）；安装前端依赖并构建；
5. 启动后端 `127.0.0.1:7001` 和前端 `127.0.0.1:5173`，并尝试打开浏览器。只监听本机，局域网其他电脑访问不到。

停止：在终端按 Ctrl+C（Windows：关闭“截图转代码-后端”窗口和运行脚本的窗口）。

## 国内镜像开关
默认不用镜像。网络慢时启用：
- Linux / macOS：`USE_CN_MIRROR=1 bash start_linux.sh`（mac 可在终端里 `USE_CN_MIRROR=1 ./start_mac.command`）
- Windows：用记事本打开 `start_windows.bat`，把第 12 行 `if "%USE_CN_MIRROR%"=="" set USE_CN_MIRROR=0` 改成 `set USE_CN_MIRROR=1`

启用后 Python 包走阿里云 PyPI 镜像，npm 包走 registry.npmmirror.com。uv 本身的安装脚本仍从官网下载，如失败请按 FAQ 手动安装 uv。

## 端口
被占用时可改：`FRONT_PORT=5180 BACK_PORT=7010 bash start_linux.sh`（Windows 改脚本里的同名变量）。

## backend/.env 里的社区版设置
| 变量 | 默认 | 说明 |
|---|---|---|
| OPENAI_BASE_URL | https://api.moonshot.cn/v1（Kimi） | 接口地址；页面「设置」里填的优先。备选硅基流动 https://api.siliconflow.cn/v1 |
| CUSTOM_MODEL_NAME | kimi-k2.6 | 模型名；页面里填的优先。备选硅基流动 Qwen/Qwen3-VL-32B-Instruct |
| CUSTOM_NUM_VARIANTS | 1 | 一次生成几个版本。每多一个就多花一倍请求 |
| OPENAI_MAX_RETRIES | 0 | 服务商出错时自动重试次数。**默认 0 = 不自动重试**，避免悄悄多花免费额度；想自动重试改成 1 |
| DISABLE_SCREENSHOT_PREVIEW | 1 | 关闭“生成后自己截图检查”，省请求 |
| SCREENSHOT_REFERENCE_ONLY | 1 | 上传的截图只当参考，不再让模型把它存成页面素材 |

**不要把 Key 写进 .env 再发给别人。** 推荐只在页面里输入 Key。
