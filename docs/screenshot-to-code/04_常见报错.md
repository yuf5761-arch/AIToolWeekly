# 04 常见报错

| 现象 | 原因 | 处理 |
|---|---|---|
| `没找到 Node.js` / `版本太旧` | 没装或版本 < 20 | 装 Node.js 20+ 后重开终端 |
| 安装依赖很慢或超时 | 网络 | 打开国内镜像开关（见一键启动说明），重试 |
| `curl ... uv` 失败 | 下载 uv 失败 | 手动安装 uv：https://docs.astral.sh/uv/ ，再运行脚本 |
| `Port 5173 is in use` | 端口被占 | 换端口：`FRONT_PORT=5180 BACK_PORT=7010 bash start_linux.sh` |
| 页面打开但生成没反应 | 后端没起来 | 看终端里有没有后端报错；确认 7001 没被占用 |
| 401 / Key 无效 | Key 填错或过期 | 重新填写 Key（刷新页面后要重填） |
| 429 Too Many Requests | 免费模型限流 | 等一会儿再点「重试」；不要连点 |
| 502 / 503 / 服务商报错 | 免费模型的上游服务商临时故障 | 等一会儿点「重试」；或在 .env 把 `OPENAI_MAX_RETRIES` 设为 1 让它自动重试一次（会多花请求） |
| 模型不存在 / 不支持图片 / 不支持工具调用 | 模型名填错，或该模型不支持看图/函数调用，或接口类型不对（Responses / Chat Completions） | 换模型；或在 .env 设 `OPENAI_API_STYLE=chat`/`responses`；以服务商文档为准 |
| 402 / Insufficient Balance / 余额不足 | 服务商账号余额为 0 或赠送额度用完 | 到该平台充值或换一家 |
| 硅基流动等待很久（几分钟） | 该模型生成慢（实测 2–5 分钟） | 耐心等，或换 Kimi |
| 生成的页面和截图差很多 | 模型能力有限 | 换更强的模型；或用文字补充要求再修改。本包不承诺效果 |
