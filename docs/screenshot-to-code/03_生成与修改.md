# 03 生成与修改

1. 「新建」→「上传」：把**你自己的**设计稿/截图拖进来（PNG/JPG，最多 5 张；或 1 段视频）。
2. 选择技术栈（默认 HTML + Tailwind），点「生成代码」。
3. 左边能看到步骤进度，右边是预览。上方可切换桌面端/移动端、看代码、下载代码。
4. 想改：在左下输入框用中文描述，比如“把按钮改成蓝色”，回车发送。也可以点「选择并修改」先在预览里点中某个元素。
5. 不满意或报错：点消息下方的「重试」。

## 社区版的两个改动
- **只生成 1 个版本**（原版默认多个，每个都要花请求）。想要多个，在 backend/.env 改 `CUSTOM_NUM_VARIANTS`。
- **截图只当参考图**：原版会让模型把你上传的截图本身存成页面素材再塞进页面，经常白花一次请求，生成的页面里还会直接贴着原截图。社区版默认关掉这个（`SCREENSHOT_REFERENCE_ONLY=1`），模型要照着截图用代码画出来。

## 用途限制
只能用于你自己的设计稿或有授权的素材。**禁止**抄袭、复制他人的网站或设计。
